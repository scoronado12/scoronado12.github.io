I build the platforms that software teams ship on. That means the cloud infrastructure, the CI/CD pipelines and the developer tooling that let a team write code and get it running without fighting the plumbing.

I work mostly with Azure, Kubernetes and GitLab. I like the unglamorous parts that keep everything up: DNS, authentication, registries and build systems. I'm happiest when a team forgets the platform is there.

software-factories/

I stand up software factories and onboard teams onto them, so a new team starts with a working pipeline, hosting and tooling instead of a blank page.

cloud-platforms/

I design and run cloud-native services on Azure Kubernetes, from high-availability public-facing apps to the Atlassian tools teams use every day. I also handle the networking and identity side: private DNS, Microsoft Entra ID sign-in and hybrid routing between on-prem and cloud.

ci-cd-and-source-control/

I run GitLab for thousands of daily users, move teams off legacy source control and build the automated pipelines that test and package their software, including Windows builds. When a pipeline or a VM breaks, I help the team get unstuck.

teaching-and-community/

I like explaining how things work. I have led a Linux users group, organized a hackathon, helped build a Beowulf research cluster and tutored intro programming students.
